## Что это

Системный плагин Joomla 6, который вставляет на страницы сайта произвольные фрагменты HTML и JavaScript: код Яндекс Метрики, Google Analytics, онлайн-чат, виджет обратного звонка, пиксель соцсети и тому подобное. Не нужно править шаблон или заводить отдельный модуль под каждый счётчик.

## Возможности

- 🗂 **Все коды в одном месте.** Таблица в настройках плагина: название, место вставки, состояние, код.
- 🔀 **Порядок вставки.** Строки можно перетаскивать, фрагменты выводятся в том порядке, в каком стоят в таблице.
- 📍 **Два места вставки.** Перед `</head>` или перед `</body>`.
- 🔘 **Включение по одному.** Выключили строку — код пропал со страниц, а запись осталась в таблице.
- 🪶 **Лёгкий.** Без базы данных, без лишних запросов, без зависимостей.
- 🛡 **Только публичная часть.** В админке и в ответах не в формате HTML (JSON, XML, скачивание файлов) плагин ничего не добавляет.
- 🔄 **Обновления через Joomla.** Новые версии приходят в стандартный раздел обновлений расширений.

## Установка

Требования: Joomla 6, PHP 8.3 или новее.

В админке откройте **Система → Установка → Расширения → «Установить по URL-адресу»** и вставьте ссылку на последнюю версию:

```text
https://github.com/shivayanamahom/plg_system_dharma_sitescripts/releases/latest/download/plg_system_dharma_sitescripts.zip
```

Или скачайте zip на странице [Releases](https://github.com/shivayanamahom/plg_system_dharma_sitescripts/releases) и загрузите его на вкладке «Загрузить файл пакета».

После установки: **Система → Плагины**, найдите **«Dharma Site Scripts»**, включите и заполните таблицу кодов.

## Как пользоваться

Откройте настройки плагина и нажмите «+», чтобы добавить строку:

| Поле | Что делает |
|---|---|
| **Название** | Подпись для вас (например, «Яндекс Метрика» или «Онлайн-чат»). На сайте не выводится. |
| **Место вставки** | `Перед </head>` или `Перед </body>`. |
| **Состояние** | Включён или выключен. Выключенный код не выводится. |
| **Код** | Любой HTML и JavaScript, например полный блок `<script>…</script>` из кабинета сервиса. |

Пример заполнения:

| Название | Место вставки | Состояние | Код |
|---|---|---|---|
| Яндекс Метрика | Перед `</head>` | вкл | код счётчика из кабинета Метрики |
| Онлайн-чат | Перед `</body>` | вкл | виджет чата |
| Тестовый пиксель | Перед `</body>` | выкл | пока не нужен |

### Куда попадает код

```html
<head>
  …
  <!-- сюда: фрагменты «Перед </head>» -->
</head>
<body>
  …
  <!-- сюда: фрагменты «Перед </body>» -->
</body>
```

- Код для `</head>` добавляется через документ Joomla, код для `</body>` вставляется в готовый HTML-ответ перед последним закрывающим тегом `body`.
- Пустые фрагменты пропускаются.
- После изменений очистите кэш Joomla и внешних кэширующих систем (CDN, кэш-плагины), иначе изменения могут не появиться сразу.

## Безопасность

> [!WARNING]
> В поле «Код» разрешён **любой** HTML и JavaScript, он вставляется на страницы как есть, без проверки и очистки. Это скрипт с полными правами на вашем сайте.

- Открывайте настройки плагина только доверенным администраторам.
- Вставляйте код только из проверенных источников и из личных кабинетов сервисов.
- Аналитика и виджеты часто ставят куки и собирают данные посетителей. Позаботьтесь о политике конфиденциальности и о согласии посетителей. Для простого уведомления о куки есть отдельный плагин [Dharma Cookie](https://github.com/shivayanamahom/dharma-cookie) (он не блокирует скрипты до согласия).
